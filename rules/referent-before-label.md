# Referent before label

<!-- codex-runtime-summary -->
- IMPORTANT: 設計、調査報告、原因切り分け、対策案、命名、推論順序の要約で新しい名称・抽象語を導入する場合は `referytale` skill を使用する。
- IMPORTANT: 指示対象を確定する前に名称を作らない。対象・役割・前後関係が確定していない内容を作業ラベルで覆わない。
- IMPORTANT: 対応表に存在しない新規語を対象本文へ直接導入しない。新しい語が必要になった場合はPhase 1へ戻る。
<!-- /codex-runtime-summary -->

設計・調査・命名では、「語を先に作り、その語に対象を合わせる」生成順序を禁止する。

新しい名称や抽象語が必要になる作業では `referytale` skill を使用する。

詳細な手順、対応表の形式、検証方法、問題発生時の戻り方は `referytale` skill を正本とする。このRuleでは個別の誤用語を管理しない。
