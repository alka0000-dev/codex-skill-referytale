| R2 | 利用者セッションゼロ条件 | 新規語 | 利用者セッションゼロ条件とは、アクティブな利用者セッションの件数が0件であるという、保守モード開始要求の送信に必要な開始条件を指す。 |
| R3 | 予定開始時刻到達条件 | 新規語 | 予定開始時刻到達条件とは、現在時刻が予定開始時刻に達しているという、保守モード開始要求の送信に必要な開始条件を指す。 |
| R4 | 保守モード開始要求送信 | 新規語 | 保守モード開始要求送信とは、三つの開始条件をすべて満たした場合だけ、管理サービスへ保守モード開始要求を1回送る事象を指す。 |
| R5 | 開始済み応答待ち状態 | 新規語 | 開始済み応答待ち状態とは、管理サービスへ保守モード開始要求を送った後、管理サービスから開始済みの応答を受ける前であり、同じ要求を再送しない状態を指す。 |

| R10 | 保守モード開始監査記録 | 新規語 | 保守モード開始監査記録とは、要求ID、送信時刻、管理サービス応答結果を保存した監査用の記録を指す。 |
