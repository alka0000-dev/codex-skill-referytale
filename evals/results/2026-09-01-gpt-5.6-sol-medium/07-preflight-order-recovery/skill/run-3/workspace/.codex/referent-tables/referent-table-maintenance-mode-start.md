| R2 | 利用者セッション不在条件 | 新規語 | 利用者セッション不在条件とは、アクティブな利用者セッションの件数が0であるという開始条件を指す。 |
| R3 | 予定開始時刻到達条件 | 新規語 | 予定開始時刻到達条件とは、現在時刻が予定開始時刻と同じか、それより後であるという開始条件を指す。 |
| R4 | 保守モード開始許可条件 | 新規語 | 保守モード開始許可条件とは、変更承認済み条件、利用者セッション不在条件、予定開始時刻到達条件のすべてが成立しているという開始条件を指す。 |
| R5 | 保守モード開始要求送信 | 新規語 | 保守モード開始要求送信とは、管理サービスへ保守モード開始要求を送る事象を指す。 |
| R6 | 開始済み応答待ち状態 | 新規語 | 開始済み応答待ち状態とは、管理サービスへ保守モード開始要求を送った後で、管理サービスから開始済みを示す応答をまだ受けていない状態を指す。 |
| R7 | 保守モード開始済み応答受信 | 新規語 | 保守モード開始済み応答受信とは、管理サービスから保守モードが開始済みであることを示す応答を受ける事象を指す。 |

| R9 | 送信時刻 | ユーザー語 | ユーザー提示の「送信時刻」。管理サービスへ保守モード開始要求を送った時刻の値を指す。 |
