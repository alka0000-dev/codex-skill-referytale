| ID | 出典 | 目的 | 具体対象 | 役割 | 前後関係 |
|---|---|---|---|---|---|
| R1 | ユーザー入力「直近15分のエラー率が1%未満なら次の利用者グループを有効化」 | 次の利用者グループの有効化を開始してよいか判断する | 判断時点から直前15分間に観測されたエラー率が1%未満であること | 開始条件 | この条件を満たした後に、次の利用者グループの有効化を開始する |
| R2 | ユーザー入力「次の利用者グループを有効化」「開始メソッド名」 | 条件を満たした次の利用者グループへ利用範囲を広げる | 次の利用者グループの有効化を開始する操作 | 手段 | R1の成立後に実行し、操作を開始した時点でR3、R4、R5を記録する |
| R3 | ユーザー入力「対象グループ」 | どの利用者グループの有効化を開始したか残す | 有効化を開始する利用者グループを識別する値 | 値 | R2を開始した時点で記録へ含める |
| R4 | ユーザー入力「開始時刻」 | 有効化をいつ開始したか残す | 次の利用者グループの有効化を開始した時刻 | 値 | R2を開始した時点で取得し、記録へ含める |
| R5 | ユーザー入力「直前15分のエラー率」 | 有効化開始時の判断根拠を残す | 次の利用者グループの有効化を開始する直前15分間に観測されたエラー率 | 値 | R1の判定に使った値を、R2を開始した時点で記録へ含める |
| R6 | ユーザー入力「対象グループ、開始時刻、直前15分のエラー率を記録」「記録型名」 | 有効化開始の対象、時点、判断根拠を一体として追跡できるようにする | 次の利用者グループの有効化を開始した時点に、R3、R4、R5を一つにまとめた記録 | 記録 | R2を開始した時点で作成する |
| R7 | ユーザー入力「次の利用者グループを有効化した後は5分間待ち、その間は次の判定を行わない」「この期間を本文では『整定区間』と呼ぶ」 | 次の利用者グループを有効化した直後の5分間を、次の判定を行わない時間範囲として示す | 次の利用者グループの有効化を開始した時刻から5分後までの時間範囲 | 期間（既定の役割に時間範囲がないため追加） | R2を開始した時点から始まり、この時間範囲内では次のR1の判定を行わず、5分経過後に次のR1の判定を行える |
| R8 | ユーザー入力「その間は次の判定を行わないことにします」「状態名にも反映してください」 | 次の利用者グループの有効化後、次の判定を抑止すべきかシステムが区別できるようにする | R2を開始した時刻から5分が経過するまで、次のR1の判定を行わないシステムの状態 | 状態 | R2を開始した時点でこの状態となり、この状態の間は次のR1の判定を行わず、5分経過時にこの状態を終える |

| ID | 候補語 | 種別 | 初出定義 |
|---|---|---|---|
| R1 | `isLast15MinuteErrorRateBelowOnePercent` | 新規語 | `isLast15MinuteErrorRateBelowOnePercent`とは、判断時点から直前15分間に観測されたエラー率が1%未満である、という開始条件を指す。 |
| R2 | `startUserGroupEnablement` | 新規語 | `startUserGroupEnablement`とは、R1の成立後に、指定された次の利用者グループの有効化を開始するメソッドを指す。 |
| R3 | `targetGroup` | 新規語 | `targetGroup`とは、有効化を開始する利用者グループを識別する値を指す。 |
| R4 | `startedAt` | 新規語 | `startedAt`とは、次の利用者グループの有効化を開始した時刻を指す。 |
| R5 | `preceding15MinuteErrorRate` | 新規語 | `preceding15MinuteErrorRate`とは、次の利用者グループの有効化を開始する直前15分間に観測され、R1の判定に使われたエラー率の値を指す。 |
| R6 | `UserGroupEnablementStartRecord` | 新規語 | `UserGroupEnablementStartRecord`とは、次の利用者グループの有効化を開始した時点の`targetGroup`、`startedAt`、`preceding15MinuteErrorRate`を一つにまとめた記録型を指す。 |
| R7 | 整定区間 | ユーザー語 | 整定区間とは、次の利用者グループの有効化を開始した時刻から5分後までの時間範囲を指す。 |
| R8 | `SETTLING_INTERVAL` | プロジェクト既存語 | `SETTLING_INTERVAL`とは、次の利用者グループの有効化を開始した時刻から5分が経過するまで、次のエラー率判定を行わないシステムの状態を指す。 |
