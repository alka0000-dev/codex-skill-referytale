| ID | 出典 | 目的 | 具体対象 | 役割 | 前後関係 |
|---|---|---|---|---|---|
| R1 | ユーザー入力「セッショントークン更新の設計」および後続の3要件 | 有効期限切れを避けながら、同一セッションからの重複要求を防ぎ、受信内容を監査可能にする | セッションで使用中のトークンについて、残り有効時間の判定、必要な要求の一回送信、受信待ち中の追加要求抑止、受信した値と受信時刻の保存を、この順序で行う仕組み | 手段 | 残り有効時間を判定し、必要なら要求を送り、受信まで追加要求を抑止し、受信後に値と時刻を保存する |
| R2 | ユーザー入力「残り有効時間が10分以下になったら」 | 有効期限切れより前に更新要求を開始する | 現在時刻と使用中のトークンの有効期限との差が10分以下であること | 開始条件 | 要求の送信より前に判定する |
| R3 | ユーザー入力「要求を送ってから新しいトークンを受け取るまでは」 | 同一セッションからの追加要求を抑止する期間を表す | 同一セッションから更新要求を送信済みであり、その要求に対応する新しいトークンをまだ受け取っていない状態 | 状態 | 要求の送信によって始まり、新しいトークンの受信によって終わる |
| R4 | ユーザー入力「更新要求を送信します」 | 使用中のトークンの後継となる値を取得する | 同一セッションから、使用中のトークンを新しいトークンへ更新する要求を送ったという出来事 | 事象 | R2が成立し、かつR3でないときに一度だけ起き、その直後にR3となる |
| R5 | ユーザー入力「新しいトークンを受け取る」 | 追加要求を禁止する期間の終了と監査保存の開始を特定する | 送信済みの更新要求に対応する新しいトークンを受け取ったという出来事 | 事象 | R3の間に起き、起きた時点でR3が終わり、R6とR7をR8へ保存する |
| R6 | ユーザー入力「受け取った新しいトークン」 | 受信結果を監査できるようにする | 更新要求への応答として受け取った新しいトークンの値 | 値 | R5で得られ、R7とともにR8へ保存する |
| R7 | ユーザー入力「受信時刻」 | いつ受信したかを監査できるようにする | 新しいトークンを受け取った瞬間を示す時刻 | 値 | R5が起きた時点で取得し、R6とともにR8へ保存する |
| R8 | ユーザー入力「監査用に保存」および「監査記録の型名」 | 受信した値と受信時刻を一体として追跡できるようにする | 更新要求への応答として受け取った新しいトークンの値と、その値を受け取った瞬間を示す時刻を保持する一件の記録 | 記録 | R5の後に、R6とR7を組にして保存する |

| ID | 候補語 | 種別 | 初出定義 |
|---|---|---|---|
| R1 | セッション更新境界（`SessionRefreshBoundary`） | 新規語 | セッション更新境界とは、セッションで使用中のトークンについて、残り有効時間を判定し、必要な要求を一回だけ送り、応答待ち中の追加要求を抑止し、受信した新しいトークンと受信時刻を保存する仕組みを指す。 |
| R2 | `isRefreshDue` | 新規語 | `isRefreshDue` とは、現在時刻と使用中のトークンの有効期限との差が10分以下であるという開始条件を指す。 |
| R3 | `AwaitingRefreshedToken` | 新規語 | `AwaitingRefreshedToken` とは、同一セッションから更新要求を送信済みであり、その要求に対応する新しいトークンをまだ受け取っていない状態を指す。 |
| R4 | `TokenRefreshRequested` | 新規語 | `TokenRefreshRequested` とは、同一セッションから、使用中のトークンを新しいトークンへ更新する要求を送ったという事象を指す。 |
| R5 | `RefreshedTokenReceived` | 新規語 | `RefreshedTokenReceived` とは、送信済みの更新要求に対応する新しいトークンを受け取ったという事象を指す。 |
| R6 | `refreshedToken` | 新規語 | `refreshedToken` とは、更新要求への応答として受け取った新しいトークンの値を指す。 |
| R7 | `receivedAt` | 新規語 | `receivedAt` とは、新しいトークンを受け取った瞬間を示す時刻の値を指す。 |
| R8 | `TokenRefreshAuditRecord` | 新規語 | `TokenRefreshAuditRecord` とは、更新要求への応答として受け取った新しいトークンの値と、その値を受け取った瞬間を示す時刻を保持する一件の監査記録を指す。 |
