| ID | 出典 | 目的 | 具体対象 | 役割 | 前後関係 |
|---|---|---|---|---|---|
| R1 | ユーザー入力の全要件 | セッショントークンの更新要求、重複送信の抑止、受信内容の監査保存を一つの設計として扱う | 同じセッションについて、残り有効時間が10分以下なら更新要求を送り、その要求の送信後から新しいトークンの受信までは追加の更新要求を送らず、受信した新しいトークンと受信時刻を保存する一連の仕組み | 手段 | 残り有効時間の判定、要求送信、追加送信の抑止、新しいトークンの受信、受信内容の保存の順に働く |
| R2 | ユーザー入力「残り有効時間が10分以下になったら更新要求を送信」 | 更新要求を送る時点を決める | 同じセッションで現在使用しているトークンの残り有効時間が10分以下であり、かつ、そのセッションから先に送った更新要求に対する新しいトークンをまだ待っていないこと | 開始条件 | 満たした後に、そのセッションから更新要求を送る |
| R3 | ユーザー入力「要求を送ってから新しいトークンを受け取るまでは、同じセッションから追加の更新要求を送ってはいけません」 | 同じセッションから更新要求が重複して送られることを防ぐ | あるセッションから更新要求を送った後で、その要求に対する新しいトークンをまだ受け取っていない期間 | 状態 | 更新要求を送った時点で始まり、新しいトークンを受け取った時点で終わる。この期間中は同じセッションから追加の更新要求を送らない |
| R4 | ユーザー入力「更新要求を送信」 | 同じセッションから追加の更新要求を送らない期間を開始する | 現在使用しているトークンの残り有効時間が10分以下であり、先に送った更新要求に対する新しいトークンを待っていない同じセッションから、更新要求を送ったこと | 事象 | 残り有効時間と先行する更新要求の有無を判定した後に発生し、新しいトークンを受け取るまで追加の更新要求を送らない期間を開始する |
| R5 | ユーザー入力「新しいトークンを受け取る」 | 更新要求の送信後から続いていた期間を終了し、監査用の保存を開始できるようにする | 先に更新要求を送った同じセッションが、その要求に対する新しいトークンを受け取ったこと | 事象 | 更新要求を送った後に発生し、追加の更新要求を送らない期間を終了させ、受け取った新しいトークンとその受信時刻を保存できるようにする |
| R6 | ユーザー入力「受け取った新しいトークン」 | 受け取った内容を監査できるようにする | 先に送った更新要求に対して同じセッションが受け取った新しいトークン | 値 | 新しいトークンを受け取った時点で得られ、その受信時刻とともに監査用の一件の記録へ保存される |
| R7 | ユーザー入力「受信時刻」 | 新しいトークンを受け取った時点を監査できるようにする | 同じセッションが、先に送った更新要求に対する新しいトークンを受け取った時刻 | 値 | 新しいトークンを受け取った時点で取得され、その新しいトークンとともに監査用の一件の記録へ保存される |
| R8 | ユーザー入力「受け取った新しいトークンと受信時刻は監査用に保存」 | 受け取った新しいトークンとその受信時点を後から確認できるようにする | 先に送った更新要求に対して同じセッションが受け取った新しいトークンと、そのトークンを受け取った時刻を組にして監査用に保存する一件の記録 | 記録 | 新しいトークンを受け取った後に作成して保存する |

| ID | 候補語 | 種別 | 初出定義 |

| R1 | `SessionRefresh` | 新規語 | `SessionRefresh` とは、同じセッションについて、残り有効時間に基づく更新要求の送信、送信後から新しいトークン受信までの追加送信の抑止、および受信したトークンと受信時刻の監査保存を順に行う仕組みを指す。 |
| R2 | `shouldRequestSessionRefresh` | 新規語 | `shouldRequestSessionRefresh` とは、現在のトークンの残り有効時間が10分以下であり、かつ、同じセッションが先に送った更新要求に対する新しいトークンを待っていない、という更新要求の開始条件を指す。 |
| R3 | `AwaitingRefreshedToken` | 新規語 | `AwaitingRefreshedToken` とは、同じセッションが更新要求を送った後、その要求に対する新しいトークンをまだ受け取っておらず、追加の更新要求を送ってはならない状態を指す。 |
| R4 | `SessionRefreshRequestSent` | 新規語 | `SessionRefreshRequestSent` とは、開始条件を満たした同じセッションから更新要求を送った事象を指す。 |
| R5 | `RefreshedTokenReceived` | 新規語 | `RefreshedTokenReceived` とは、先に更新要求を送った同じセッションが、その要求に対する新しいトークンを受け取った事象を指す。 |
| R6 | `refreshedToken` | 新規語 | `refreshedToken` とは、先に送った更新要求に対して同じセッションが受け取った新しいトークンの値を指す。 |
| R7 | `receivedAt` | 新規語 | `receivedAt` とは、同じセッションが、先に送った更新要求に対する新しいトークンを受け取った時刻の値を指す。 |
| R8 | `RefreshedTokenReceiptAuditRecord` | 新規語 | `RefreshedTokenReceiptAuditRecord` とは、先に送った更新要求に対して同じセッションが受け取った新しいトークンと、その受信時刻を組にして監査用に保存する一件の記録を指す。 |
