# Voice Profile Template

専用Skillがない場合に、複数の文章から限定的な文体傾向を抽出するためのテンプレート。

```markdown
# Voice Profile

## Source
- sample-1:
- sample-2:
- sample-3:

## Perspective
- 一人称:
- 読者との距離:
- 断言の強さ:

## Rhythm
- 文の長短:
- 改行:
- 段落の長さ:

## Vocabulary
- よく使う語:
- 残したい言い回し:
- 避ける語:

## Structure
- 冒頭:
- エピソード:
- 一般論への距離:
- 結び:

## Evidence
各傾向がどのサンプルから観察されたかを書く。
```

少数サンプルから人物全体を断定しない。一度だけ使った語を口癖にしない。内容上必要だった表現と文体上の好みを混同しない。
